# 2022 개정 수학 교육과정 개념 그래프

2022 개정 수학과 교육과정의 성취기준을 바탕으로, 초등학교부터 고등학교까지 이어지는 수학 개념을 선수학습 의존 관계로 정리한 one-file HTML 그래프입니다.

바로 보기: https://pycodinglec.github.io/2022-math-concept-graph/

## 무엇을 볼 수 있나

- 개념 노드 660개
- 의존 관계 1,236개
- 성취기준 435개 기반
- 방향: `개념 -> 그 개념이 의존하는 선수 개념`
- 예시: `분산 -> 평균`, `분산 -> 편차`
- 노드 크기: 진입차수 기준. 큰 노드일수록 더 많은 후속 개념이 의존하는 개념입니다.

## 조작 방법

- 노드를 왼쪽 클릭하면 해당 개념과 연결된 선수/후속 개념이 색으로 강조됩니다.
- 빈 공간이나 엣지를 왼쪽 클릭하면 강조 상태가 해제됩니다.
- 왼쪽 위 `+` 버튼을 누르면 검색, 영역 필터, 인접 리스트, 출처 패널을 열 수 있습니다.
- 검색으로 특정 개념 위치를 찾은 뒤 검색어를 지우면, 현재 view 위치를 유지한 채 전체 노드 표시로 돌아갑니다.

## 참고한 시각화

그래프의 전체 화면 구성, 흰 배경, 작은 원형 노드, 옅은 엣지, 힘 기반 배치, 선택 노드 주변 관계 강조 방식은 [seomal.org](https://seomal.org/)의 표현 방식을 참고했습니다.

다만 이 프로젝트에서는 seomal.org의 PageRank 기반 노드 크기를 그대로 쓰지 않고, 요청 조건에 맞춰 노드 크기를 진입차수에 비례하도록 조정했습니다.

## 작업 과정

1. 교육부 고시 제2022-33호 `[별책 8] 수학과 교육과정`을 기준 자료로 삼았습니다.
2. 초등학교, 중학교, 고등학교 수학 성취기준 435개를 추출했습니다.
3. 성취기준에 등장하거나 성취기준을 설명하는 데 필요한 수학 개념을 명사형 개념어로 정리했습니다.
4. 개념별 선수학습 의존 관계를 인접 리스트 형태로 모델링했습니다.
5. `개념 -> 선수 개념` 방향의 directed graph로 변환했습니다.
6. Cytoscape.js와 cose-bilkent 레이아웃으로 seomal.org와 유사한 전체 화면 그래프를 구성했습니다.
7. 외부 파일 없이 열 수 있도록 Cytoscape.js, cose-bilkent, TinyColor, 그래프 데이터를 모두 `index.html` 안에 inline으로 넣었습니다.

## 구현 메모

- 이 저장소에는 배포용 `index.html`과 설명용 `README.md`만 포함되어 있습니다.
- `index.html`은 서버 없이도 열 수 있는 standalone HTML입니다.
- 공개 페이지는 GitHub Pages의 `main` 브랜치 루트에서 배포됩니다.
- 그래프 데이터는 HTML 내부에 포함되어 있어 별도 JSON 요청이 필요 없습니다.
